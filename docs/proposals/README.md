# Propuestas y decisiones

Por instrucción del usuario del 2026-11-18, las propuestas de VOXEL también
se conservan en GitHub. No deben existir únicamente en un chat o un equipo.

Para una propuesta nueva, crear `YYYY-MM-DD-descripcion.md` con:

- Estado: propuesta, en evaluación, aceptada, rechazada o sustituida.
- Problema y contexto que la motivan.
- Alternativas, ventajas, límites y riesgos relevantes.
- Recomendación y qué decisión o información sigue pendiente.
- Validación prevista y, después, resultado o enlace al cambio que la implementa.

Una propuesta publicada no es una función disponible ni una aprobación.
Si el usuario ya autorizó el alcance, registrar esa evidencia; no inventar
una aprobación ni volver a pedirla sólo por publicar el documento.

Los diseños existentes permanecen donde están para conservar referencias:
[M01-A](../M01-A-DESIGN.md). Al tomar o cambiar una decisión, actualizar su
estado y sincronizar el documento junto con el trabajo correspondiente.
