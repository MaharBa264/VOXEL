# Visión de VOXEL

Definición de producto confirmada el 18 de noviembre de 2026.

VOXEL es una app para componer música por capas a partir de ideas que podés
tararear, silbar, marcar con golpes sobre el escritorio o escribir directamente
como una armonía. Cada parte ocupa su propia pista dentro del mismo proyecto.

## Dos formas de empezar

- **Desde una toma.** Tarareás o silbás una idea y la convertís en una pista de
  melodía o de bajo. Golpeteás la mesa o el escritorio y convertís el patrón
  en una pista de percusión. VOXEL puede proponer una armonía para lo que
  grabaste. La propuesta queda disponible para escuchar, elegir o editar.
- **Desde una armonía.** Creás directamente una progresión de acordes, la
  reproducís y tarareás o silbás encima. Convertís cada toma nueva en otra
  pista instrumental. Podés repetirlo para sumar melodía, bajo u otras partes,
  y añadir percusión con golpes.

## Composición multipista

Melodía, bajo, percusión y armonía son partes separadas que se pueden escuchar
juntas sobre una línea de tiempo común. El proyecto conserva tanto el audio
original de cada toma como el material musical generado a partir de ella.

## Hito actual

M01-A comprueba un primer recorrido de voz a MIDI y piano. Su aceptación
manual sigue siendo el punto de cierre inmediato. La visión multipista
orienta los hitos posteriores. El orden, los métodos de detección y la forma
de editar acordes quedan como decisiones de diseño futuras.
